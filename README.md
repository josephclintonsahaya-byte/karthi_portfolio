# V. Karthick — Data Analytics Portfolio

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

The supplied resume is available at `public/resume.pdf`; the hero includes open and download actions. All chart figures and SQL result rows are illustrative sample data. Resume contact details and the first page's detailed text could not be reliably extracted in this environment, so no email address, LinkedIn URL, dates, or specific internship responsibilities are fabricated.
